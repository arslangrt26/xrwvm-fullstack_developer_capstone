# xrwvm-fullstack_developer_capstone

## Project Overview
The fullstack_developer_capstone project is a full-stack web application for managing car dealerships and customer reviews. The application allows users to browse dealerships, view dealer details, register/login, and submit reviews and ratings.

This project demonstrates frontend and backend integration, REST API development, authentication, database connectivity, and deployment practices.

--------------------------------------------------

FEATURES

- User Registration and Authentication
- Dealer Listing and Dealer Details
- Add and View Dealer Reviews
- Sentiment Analysis for Reviews
- REST API Integration
- Responsive Frontend UI
- Secure Backend Services
- Database Connectivity

INSTALLATION

1. Clone Repository

git clone https://github.com/arslangrt26/xrwvm-fullstack_developer_capstone.git

2. Navigate to Project Folder

cd xrwvm-fullstack_developer_capstone

3. Install Dependencies

pip install -r requirements.txt

4. Run Server

python manage.py runserver

--------------------------------------------------

API TESTING EXAMPLE

Get Dealers:

curl -X GET http://127.0.0.1:8000/api/dealers/ \
-H "Content-Type: application/json"
